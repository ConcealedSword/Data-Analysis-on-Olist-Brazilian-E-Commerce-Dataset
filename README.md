📊 Data Analysis on Olist Brazilian E-Commerce Dataset
Welcome to my data analysis project on the Olist Brazilian E-Commerce Dataset! This project aims to uncover key insights into market performance and offer actionable recommendations for improving customer retention in the e-commerce space.

🛍️ About the Dataset
The dataset includes 100k real anonymized orders placed from 2016 to 2018 across various Brazilian marketplaces. It comprises 9 relational tables containing information on customers, orders, products, sellers, reviews, and more. All company and partner names have been anonymized using Game of Thrones house names.

📎 Dataset Source: Kaggle - Olist Brazilian E-Commerce

🎯 Project Objectives
Analyze customer behavior and purchasing patterns.

Evaluate seller and product performance.

Understand delivery timelines and review ratings.

Provide actionable insights to improve customer retention and market strategies.

📁 Files Included
Olist Project Python.ipynb: Jupyter Notebook containing all analysis, visualizations, and insights.

Data Analysis on Olist Dataset: Document summarizing the key findings and business recommendations.
